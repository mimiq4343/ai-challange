# Документация Flash Chat

Справочник по устройству проекта для разработчиков и ассистента Day 31.
Хронология заданий, запуск отдельных дней и результаты измерений описаны в
корневом [README](../README.md), правила работы с репозиторием — в
[AGENTS.md](../AGENTS.md).

- [Архитектура](architecture.md) — слои приложения, каталоги и соглашения.
- [HTTP API](api.md) — все маршруты `/api/*` по дням и форматы ответов.
- [Схема данных](data-schema.md) — файлы SQLite, таблицы и владельцы схем.
- [MCP](mcp.md) — серверы, инструменты, транспорты и авторизация.
- [Разработка](development.md) — окружение, команды, проверки и ветки.
- [Ассистент разработчика](dev-assistant.md) — команда `/help`, индекс
  документации и MCP-сервер проекта.

Документы индексируются командой `npm run dev-assistant:index`. После их
изменения индекс нужно пересоздать, иначе `/help` предупредит, что он устарел.
