При верстке лендингов и веб-страниц пользователь дважды забраковал контейнеры с
фиксированной максимальной шириной (`max-w-[1200px]`, затем даже крупные фиксированные
отступы `xl:px-20`): «По бокам пустые полосы, исправь» и «Сделай вообще динамическую
верстку, чтобы подгонялась под размер экрана».

Урок: для этого пользователя layout по умолчанию делать полностью флюидным, на всю
ширину вьюпорта. Отступы и размеры задавать через `clamp()` с vw/vh-компонентой, а не
фиксированными брейкпоинт-значениями; декоративные фоны (свечения, градиенты) растягивать
full-bleed на весь вьюпорт, чтобы их края не читались как «полосы». Жёсткие узкие
контейнеры допустимы только если пользователь сам их попросит. Читаемость длинных строк
внутри ограничивать локально (`max-w-[65ch]` на абзацах), а не сужением всей страницы.
