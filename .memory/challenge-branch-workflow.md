Проект в /srv/workspace/ai-challange — участие пользователя в челлендже
"AI Advent Challenge #9" (репозиторий github.com/mimiq4343/ai-challange).

Git-процесс, заданный пользователем: задание каждого дня челленджа делается в
отдельной ветке day-N (day-2, day-3, ...), созданной от main. Код дня вливается
в main только по явной команде пользователя; до этого main держит предыдущую
стабильную версию приложения (на момент Day 2 пользователь явно велел оставить
в main версию приложения Day 1).

Правила README (пользователь поправлял дважды, соблюдать без напоминаний):

- В каждой ветке day-N — README с описанием задания этого дня.
- В main — сводный README-хронология: структура веток, описание каждого дня,
  как запустить каждый день (git checkout day-N + команды). Обновлять его СРАЗУ,
  как только появляется или существенно меняется ветка нового дня, не дожидаясь
  merge кода в main: README в main живёт отдельно от кода приложения в main.
