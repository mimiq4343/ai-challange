# Проверка Day 34

Дата: 2026-10-18. Ветка: `day-34`. Модель реальных запросов:
`deepseek-v4-flash`. Интерфейс: `/day-34`, настоящий локальный stdio MCP.

## Реальные сценарии

- **Поиск:** запрос об использованиях `ConversationSidebar`. Модель вызвала
  `search_files`, `list_files`, два `read_file` и уточняющий `search_files`.
  Нашла определение компонента, импорт и JSX в `conversation-workspace.tsx`,
  отделила текстовые упоминания. Первый поиск просмотрел 444 доступных файла,
  `skipped=[]`, `truncated=false`. Это буквальный поиск; полнота по алиасам
  и динамическим обращениям не проверяется.
- **Создание:** чтение `file-assistant-files.ts` и конфигурации, предложение
  `docs/day-34-browser-probe.md`. Четыре вызова, 13,6 с по интерфейсу.
  До Apply файла на диске не было. После Apply он появился: 3 813 байт.
- **Обновление:** чтение созданного документа и конфигурации, `propose_file`
  с `edits` для заголовка. Три вызова, 6,6 с. Diff содержал одну замену,
  после Apply заголовок изменился, остальной документ сохранился; 3 819 байт.
  Проверочный файл удалён после проверки и не входит в продукт.

Модель подготовила 31 строку при просьбе «до 30 строк». Наличие вызовов и
валидность diff не гарантируют соблюдения всех смысловых требований.
Результаты требуют просмотра перед применением.

## Автоматические и браузерные проверки

- `npm run test:files`: 14 тестов реальной файловой системы, точечных замен,
  конфликтов, ссылок, доступа, stdio MCP, выбора инструментов моделью через
  управляемый провайдер и HTTP. Большой README сохраняется при точечной правке.
- Независимое ревью выявило искажение строк `-- текст` / `++ текст` в diff:
  они ошибочно принимались за заголовки файлов. Регрессионный тест сначала
  упал; после ограничения переписывания областью до первого hunk прошёл.
- `npm run test:dev-assistant`: 18 тестов предыдущего режима.
- `npm run test:mcp`: 78 тестов общего tool-loop, SSE и MCP.
- Scoped ESLint и `npx tsc --noEmit` прошли.
- Реальные три сценария отображались на 1440 и 390 px без горизонтального
  переполнения и интерактивных целей меньше 44×44 px.
- [`file-assistant-focus.mjs`](../../../tests/browser/file-assistant-focus.mjs)
  с контролируемыми ответами сначала воспроизвёл потерю фокуса после Apply,
  после исправления прошёл на обеих ширинах. Подтверждённый статус получает
  фокус; переполнения и маленьких целей нет.
- На `/day-7` проверены desktop и mobile, открытие drawer клавиатурой,
  фокус внутри drawer, Escape и возврат фокуса. Запросы к модели и изменения
  существующих диалогов для этой проверки не выполнялись.
- `/day-31`: браузерная команда `/help` завершилась без ошибки и сохранила
  прежние инструменты. Меню дней закрывается по Escape с возвратом фокуса.

## Пределы проверки

Запись в исходники не предусмотрена согласованным объёмом. Нет общей
транзакции нескольких файлов. Проверяется актуальность целевого файла,
но не всех исходников, прочитанных для документа. Origin не заменяет
авторизацию: сетевой доступ к приложению позволяет менять документацию.
Против одновременной враждебной замены каталогов локальным процессом
изоляция на уровне ОС не вводилась. Истёкшие предложения остаются в базе,
хотя применить их нельзя.

Production build и слияние в `main` не запускались: интеграция дня не запрошена.
Обновление отдельного README в `main` отклонено автоматической проверкой
разрешений как изменение общей ветки без явного согласия в текущем запросе.
Подготовлен [patch только README](main-readme.patch); сама `main` не менялась.
