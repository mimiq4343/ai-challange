# Flash Chat

Проект для челленджа **AI Advent Challenge #9**, задание **Day 4**.
Автор: **Roman Sukhin** (@mimiq43).

Лендинг-плейграунд для диалога с любой OpenAI-совместимой моделью (DeepSeek,
OpenAI, OpenRouter, Ollama и т.п.): стриминговые ответы через серверный маршрут
Next.js, API-ключ не покидает сервер.

Стек: Next.js 16 (App Router), TypeScript, Tailwind CSS v4.

## Задание Day 4: температура

Один и тот же запрос уходит при `temperature = 0`, `0.7`, `1.2` и `1.7`, ответы
сравниваются по точности, креативности и разнообразию. Страница — `/day-4`.

Каждая температура получает **три ответа**, а не один: разнообразие — это
свойство выборки, по единственному ответу его измерить нечем. Итого двенадцать
запросов на прогон плюс тринадцатый — запрос-судья.

Всё, кроме температуры, у четырёх колонок одинаковое: `max_tokens: 400`,
`thinking: {"type":"disabled"}`, один и тот же текст запроса.

### Что измеряется

| Метрика | Как считается |
| ------- | ------------- |
| Точность | у задач с эталоном ответ заканчивается строкой `ОТВЕТ: <значение>`, она нормализуется и сверяется со списком допустимых форм |
| Уникальных | сколько из трёх ответов различны после нормализации |
| Разнообразие | 1 − средняя попарная мера Жаккара по словам: 0 — тексты совпадают, 100% — не пересекаются вовсе |
| Лексика | доля уникальных слов во всей выборке температуры |
| Креативность и связность | оценки 1–5 от запроса-судьи: он получает все девять ответов разом и работает при `temperature: 0` и `response_format: json_object`, чтобы его собственные оценки не плавали |

Судья также помечает дефект каждого ответа, если находит: фактическую ошибку,
нарушение формата, оборванную мысль.

### Задачи

Две задачи с проверяемым ответом и две открытые — температуру нужно смотреть и
там, где верный ответ один, и там, где его нет.

| Задача | Тип | Эталон |
| ------ | --- | ------ |
| Сколько минут в 3 сутках и 7 часах? | точность | 4740 |
| Какая буква стоит на седьмом месте с конца в слове «делопроизводство»? | точность | в |
| Слоган для кофейни на вокзале, до восьми слов | креатив | — |
| Объясни рекурсию одной метафорой, до сорока слов | объяснение | — |

Плюс поле «Свой запрос» с необязательным эталонным ответом.

### Разнообразие

Единственная метрика, которая растёт монотонно и на всех задачах: слоган 72% →
86% → 91% → 93%, метафора 50% → 76% → 84% → 98%. Вместе с ней растёт лексическое
богатство. Основной прирост даёт переход от 0 к 0.7; дальше кривая пологая, пока
не начинается 1.7, где тексты почти перестают пересекаться словарём — но уже по
другой причине, см. ниже.

### Креативность

Пик приходится не на максимум температуры, а на середину — и зависит от длины
ответа. На коротком слогане креативность растёт до самого конца (2.3 → 3.3 → 3.3
→ 4.0): восемь слов не успевают развалиться. На метафоре в сорок слов картина
обратная — 2.3 → 3.0 → 3.0 → 2.3: при 1.7 судья снизил оценку, потому что оценивать
стало нечего.

Вот третий ответ про рекурсию при 1.7 целиком:

```
Рекурсия — это как две зеркала друг напротив друга: чтобы дойти до сути этой
настоящей вещи, ты её вызывает в грилли, делая это зависшей он понимаенье не
пистей красицавицаши с формачатор и само обла). Файлайнка всё еще рамбукот,
рефрамите свои части линяет
```

В соседнем ответе той же колонки модель написала «Россiйская матрёшка» — через
дореформенную «i». Это и есть цена экстремального сэмплинга: маловероятные
токены получают шанс не только там, где они уместны.

### Точность

В этом прогоне арифметика устояла при всех четырёх температурах (4740 во всех
двенадцати ответах), а задача с буквой по позиции не далась ни разу (0/3
везде — модели без пошагового рассуждения она не по силам). Но в предыдущем
прогоне, где 1.7 стояла третьей колонкой, один ответ из трёх дал
`4320 + 420 = 4500`. То есть **при 1.7 нестабильны и сами результаты**: два
прогона одной задачи расходятся по точности, чего при 0–1.2 не происходило.

Связность — вот что ломается предсказуемо. При 0–1.2 она держится на 4.7–5.0
почти везде, при 1.7 падает до 3.7 на символьной задаче и до 3.3 на метафоре, а
ответы раздуваются: 23 слова → 48 на букве, 26 → 69 на метафоре.

Отдельное наблюдение: **`temperature: 0` не даёт побайтовой воспроизводимости**.
На счётной задаче и на метафоре при нуле получилось по 2 разных ответа из 3.
Нулевая температура убирает случайность сэмплинга, но не недетерминированность
самого сервиса, поэтому полагаться на неё как на замену кэшу нельзя.

## Для каких задач какая настройка

- **`temperature: 0`** — извлечение данных, классификация, код, расчёты,
  парсинг, автотесты, любые пайплайны, где ответ должен повторяться. Обратная
  сторона: переформулировать неудачный ответ бесполезно, придётся менять
  промпт.
- **`temperature: 0.7`** — рабочий диапазон для текста: письма, описания,
  объяснения, ответы в чате, черновики документации. Формулировки живые, смысл
  держится; для проверяемых задач сверка всё равно нужна.
- **`temperature: 1.2`** — черновики идей и вариативные тексты: несколько
  заходов на один и тот же абзац, разные подачи одной мысли. Разброс уже широкий
  (59–91% различий), а связность ещё на уровне 4.7–5.0.
- **`temperature: 1.7`** — только короткие формы в режиме брейншторма: слоганы,
  названия, заголовки, где человек отбирает лучшее из пула. На ответах длиннее
  пары строк начинается распад: бессвязные куски, лишние токены, вдвое-втрое
  раздутый текст и нестабильная от прогона к прогону точность.

## Запуск

```bash
cp .env.example .env.local   # заполните OPENAI_BASE_URL, OPENAI_API_KEY, OPENAI_MODEL
npm install
npm run dev
```

Приложение поднимется на http://localhost:3000, страница задания — на
http://localhost:3000/day-4.

Если открывать приложение не с самой машины разработки, а по её сетевому адресу,
этот адрес нужно перечислить в `allowedDevOrigins` в `next.config.ts`: Next 16
блокирует dev-ресурсы (`/_next/hmr` и клиентские чанки) для чужого origin, и
страница приходит негидрированной — кнопки не реагируют на нажатия.

## Конфигурация (.env.local)

- `OPENAI_BASE_URL` — базовый URL провайдера, например `https://api.deepseek.com/v1`.
- `OPENAI_API_KEY` — ключ API.
- `OPENAI_MODEL` — имя модели, например `deepseek-v4-flash`. Показывается на
  сайте динамически.

## Как устроено

- `src/lib/day4.ts` — температуры, задачи с эталонами, промпт судьи, разбор его
  JSON и метрики разнообразия (`diversityStats`, мера Жаккара, доля уникальных
  слов).
- `src/lib/day4-runner.ts` — запросы: один ответ при заданной температуре и
  отдельный вызов судьи со строгим JSON.
- `src/components/temperature-lab.tsx` — выбор задачи, параллельный запуск девяти
  ответов, отмена, вызов судьи после прогона.
- `src/components/temperature-column.tsx` — колонка одной температуры: метрики и
  три ответа с вердиктом и оценками.
- `src/components/temperature-summary.tsx` — сводная таблица и рекомендации по
  выбору температуры.
- `src/app/api/chat/route.ts` — серверный маршрут: проксирует запрос в
  OpenAI-совместимый API (`stream: true`), превращает SSE в текстовый поток,
  валидирует необязательные `system`, `temperature`, `max_tokens`,
  `response_format` и `thinking`.
- `src/app/page.tsx` и `src/components/chat.tsx` — лендинг и чат из задания
  Day 1: стриминг, остановка генерации, Markdown-рендер ответов.
