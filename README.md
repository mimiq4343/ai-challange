# Flash Chat

Проект для челленджа **AI Advent Challenge #9**, задание **Day 5**.
Автор: **Roman Sukhin** (@mimiq43).

Лендинг-плейграунд для диалога с любой OpenAI-совместимой моделью (DeepSeek,
OpenAI, OpenRouter, Ollama и т.п.): стриминговые ответы через серверный маршрут
Next.js, API-ключ не покидает сервер.

Стек: Next.js 16 (App Router), TypeScript, Tailwind CSS v4.

## Задание Day 5: слабая, средняя и сильная модель

Один и тот же запрос при одинаковых настройках уходит на три модели разного
класса, а страница `/day-5` показывает, чем они отличаются по качеству,
скорости и ресурсоёмкости.

| Класс | Модель | Провайдер | Вход $/1M | Выход $/1M |
| ----- | ------ | --------- | --------: | ---------: |
| слабая | `deepseek-v4-flash` | DeepSeek | 0.22 / 0.44 | 0.66 / 1.32 |
| средняя | `openai/gpt-oss-120b` | Groq | 0.15 | 0.60 |
| сильная | `deepseek-v4-pro` | DeepSeek | 0.66 / 1.32 | 1.98 / 3.96 |

У DeepSeek две цены: льготная и пиковая. Пик — 01:00–04:00 и 06:00–10:00 UTC по
будням, в остальное время тариф ровно вдвое ниже; приложение выбирает нужный по
времени запроса и подписывает, какой применился. Groq берёт одну цену
круглосуточно.

Слабая и сильная модели — из одного семейства, поэтому разница между ними это
разница класса, а не провайдера. Средняя стоит на чужом железе (LPU Groq): по
способностям она между ними, по скорости — вне конкуренции.

### Что уравнено

Всё, кроме модели: общий system prompt, `temperature: 0`, `max_tokens: 1200`,
один и тот же текст запроса. Различается только глубина рассуждения, и её
уравнять до конца нельзя: у моделей DeepSeek стоит `thinking: {"type":"disabled"}`,
а `gpt-oss-120b` рассуждать не перестаёт — ей выставлен минимальный
`reasoning_effort: "low"`. Скрытые токены рассуждения видны в метриках отдельной
строкой и оплачиваются как обычный выход.

### Что измеряется

| Метрика | Как считается |
| ------- | ------------- |
| Первый токен | время от отправки запроса до первого токена ответа, замер на сервере |
| Весь ответ | время до последнего токена |
| Скорость | токенов ответа в секунду после первого токена — чистая скорость генерации без задержки на старте |
| Токены | `usage` самого провайдера: вход, выход и скрытые токены рассуждения внутри выхода |
| Стоимость | токены, умноженные на тариф провайдера, действовавший в момент запроса; попадание в кэш промпта у DeepSeek считается по своей, в 30 раз меньшей цене |
| Точность | у задач с эталоном ответ заканчивается строкой `ОТВЕТ: <значение>`, она нормализуется и сверяется со списком допустимых форм |
| Качество | оценки 1–5 от слепого судьи: ответы приходят к нему под метками A, B и C в перемешанном порядке, без имён моделей |

Время меряется на сервере, а не в браузере: в клиентский замер попали бы
перерисовки React и задержки самой страницы. Судья работает при `temperature: 0`
и `response_format: json_object`, чтобы оценки были воспроизводимы.

### Задачи

Три задачи с проверяемым ответом и две открытые: разницу классов нужно видеть и
там, где верный ответ один, и там, где его оценивает только судья.

| Задача | Тип | Эталон |
| ------ | --- | ------ |
| У Марии четыре брата и три сестры. Сколько сестёр у брата Марии? | логика | 4 |
| Цену 4800 ₽ подняли на 25%, затем дали скидку 20% | счёт | 4800 |
| Сколько букв «р» в слове «перераспределение»? | буквы | 3 |
| Разница между процессом и потоком одной метафорой, до сорока слов | объяснение | — |
| Функция `debounce` на TypeScript с типами и методом `cancel` | код | — |

Плюс поле «Свой запрос» с необязательным эталонным ответом.

## Короткий вывод

**Скорость измеряется железом, а не размером модели.** `gpt-oss-120b` на LPU
Groq выдаёт 500–2400 токенов в секунду и заканчивает ответ за 0.6 с — в 3.5 раза
быстрее сильной модели и в 2.2 раза быстрее слабой, хотя генерирует при этом
больше всех токенов. Слабая модель быстрее сильной ровно потому, что она
меньше: 1.4 с против 2.2 с.

**Дешёвый токен и дешёвый ответ — не одно и то же.** У `gpt-oss-120b` тариф
ниже, чем у `deepseek-v4-flash` (0.15/0.60 против 0.22/0.66), но на тех же
задачах она вышла на 30% дороже: 691 токен выхода против 419, из них 278 —
скрытые токены рассуждения, за которые платят как за обычный ответ.
Ресурсоёмкость модели считается по счёту, а не по прайсу.

**Разница классов видна там, где нужен вывод, а не пересказ.** На пяти задачах
единственную ошибку сделала слабая модель — и в самой простой на вид задаче про
сестёр: она забыла, что Мария тоже сестра своих братьев, и ответила 3 вместо 4.
Арифметику с процентами и счёт букв взяли все три. Средняя модель ошиблась не в
фактах, а в коде: её `debounce` возвращает `Promise`, замаскированный
`as unknown as R`, — судья снял за это до 2 из 5, а обе модели DeepSeek написали
корректную обёртку.

**Сильная модель окупается не всегда.** Она дороже слабой в 2.9 раза и медленнее
в 1.6 раза, а выигрывает только на задачах, где нужен аккуратный вывод: средняя
оценка судьи 4.9 против 4.2 и 4.1. Для потоковых задач — классификация,
извлечение полей, короткие ответы — платить за неё нечем; для кода и логики
разница уже осязаема.

**Практический вывод.** Слабая модель — для объёма, средняя на быстром железе —
там, где важна задержка (интерактивный интерфейс, голос, автодополнение), а
сильная — для задач с ценой ошибки. Смешивать провайдеров ради этого не дороже,
чем держать одного: разница в счёте между всеми тремя на пяти задачах — доли
цента.

Оговорка о судье: он работает на `deepseek-v4-pro`, то есть на одной из
сравниваемых моделей. Ответы приходят к нему обезличенными и в перемешанном
порядке, но полностью исключить симпатию к собственному стилю это не может — в
задаче про буквы он, например, поднял свой ответ выше ответа Groq за
формулировку, а не за фактическую разницу.

## Как запустить

```bash
npm install
cp .env.example .env.local   # заполнить ключи
npm run dev
```

Странице `/day-5` нужны оба провайдера, странице `/` — только первый:

```
OPENAI_BASE_URL=https://api.deepseek.com/v1
OPENAI_API_KEY=sk-...
OPENAI_MODEL=deepseek-v4-flash

GROQ_BASE_URL=https://api.groq.com/openai/v1
GROQ_API_KEY=gsk_...
```

Имена моделей эксперимента и их тарифы лежат в `src/lib/day5.ts`: в окружении
только ключи и адреса. Ключи не покидают сервер — браузер обращается к
маршрутам `/api/chat` и `/api/day5` того же приложения.

## Структура

```
src/
  app/
    api/chat/route.ts    стриминговый прокси к OpenAI-совместимому API (Day 1)
    api/day5/route.ts    прогон одной модели с замером времени, токенов и стоимости
    day-5/page.tsx       страница задания Day 5
    page.tsx             лендинг с чатом (Day 1)
  components/
    chat.tsx             чат с историей и остановкой генерации
    day5-lab.tsx         выбор задачи, параллельный прогон трёх моделей, судья
    day5-summary.tsx     сводная таблица, автоматический вывод и ссылки
    model-column.tsx     колонка одной модели: ответ и метрики
    site-header.tsx      шапка с навигацией
  lib/
    day5.ts              модели, тарифы, задачи, проверка ответа, промпт судьи
    day5-runner.ts       вызовы маршрута и разбор NDJSON-потока с метриками
```
