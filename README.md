# AI Advent Challenge #9

Автор: **Roman Sukhin** (@mimiq43).

Репозиторий участия в челлендже **AI Advent Challenge #9**: одно
Next.js-приложение, задание каждого дня делается в отдельной ветке и вливается
в main по мере готовности. Подробный README каждого дня лежит в его ветке.

Стек: Next.js 16 (App Router), TypeScript, Tailwind CSS v4. Работает с любым
OpenAI-совместимым API (DeepSeek, OpenAI, OpenRouter, Ollama и т.п.).

## Структура веток

| Ветка   | Что в ней                                                  |
| ------- | ---------------------------------------------------------- |
| `main`  | Стабильная версия приложения (сейчас Day 1) + этот README  |
| `day-1` | Day 1 «Лендинг-чат»                                        |
| `day-2` | Day 2 «Формат ответа»                                      |
| `day-3` | Day 3 «Способы рассуждения»                                |
| `day-4` | Day 4 «Температура»                                        |

## Хронология

### Day 1 · Лендинг-чат — ветка `day-1`, страница `/`

Flash Chat: лендинг с полноэкранным чатом для любой OpenAI-совместимой модели.
Стриминг ответов по SSE, Markdown-рендер, остановка генерации, кнопка «Новый
диалог». Ключ и конфиг провайдера в `.env.local`, в браузер не попадают; имя
модели на странице показывается динамически из env.

### Day 2 · Формат ответа — ветка `day-2`, страница `/day-2`

Один и тот же запрос уходит дважды и сравнивается бок о бок: без ограничений
против тематического агента «Кино-консьерж» с жёстким контролем ответа
(`response_format: json_object`, `max_tokens: 600`, `stop: ["END"]`,
`thinking: disabled`, system prompt со схемой ответа). Вопрос не по теме кино
получает JSON-отказ `{"status":"refused", ...}`.

### Day 3 · Способы рассуждения — ветка `day-3`, страница `/day-3`

Одна задача решается четырьмя способами сразу: прямой ответ без инструкций,
пошаговое решение, промпт, который модель пишет себе сама и затем решает по
нему, и группа экспертов (аналитик, инженер и критик отвечают параллельно, ещё
один запрос сводит их мнения). Условия у всех одинаковые — `temperature: 0`,
`thinking: disabled`, общий формат финальной строки, — поэтому различается
только способ рассуждения. Ответ каждого способа автоматически сверяется с
эталоном задачи, а сводная таблица сравнивает точность с временем, длиной
ответа и числом запросов к API. В прогоне на `deepseek-v4-flash` пошаговое
решение дало 4 верных ответа из 4, прямой ответ и мета-промпт — по 3, группа
экспертов — 2 при вчетверо большей цене.

### Day 4 · Температура — ветка `day-4`, страница `/day-4`

Один и тот же запрос уходит по три раза при `temperature` 0, 0.7, 1.2 и 1.7:
повторы нужны, чтобы разнообразие можно было измерить, а не только заметить.
Точность сверяется с эталоном задачи, разнообразие считается как доля уникальных
ответов и попарная лексическая непохожесть, а креативность и связность оценивает
отдельный запрос-судья при нулевой температуре. В прогоне на `deepseek-v4-flash`
разнообразие росло монотонно на всех задачах (слоган 72% → 86% → 91% → 93%), а
креативность упиралась в длину ответа: на восьмисловном слогане она поднималась
до самого верха (2.3 → 4.0), а на сорокасловной метафоре 1.7 откатилась к уровню
нулевой температуры, потому что один ответ выродился в бессвязный набор слов.
Связность при 0–1.2 держится на 4.7–5.0 и обваливается только при 1.7. Отдельная
находка: `temperature: 0` не даёт побайтовой воспроизводимости — при нуле ответы
тоже расходятся.

## Запуск любого дня

```bash
git checkout day-N           # нужный день, например day-2
cp .env.example .env.local   # заполните OPENAI_BASE_URL, OPENAI_API_KEY, OPENAI_MODEL
npm install
npm run dev
```

Если открывать приложение по сетевому адресу машины, а не с неё самой, этот
адрес должен быть перечислен в `allowedDevOrigins` в `next.config.ts` (начиная с
ветки `day-3` там уже есть такая настройка): Next 16 блокирует dev-ресурсы для
чужого origin, и страница приходит негидрированной.

- Day 1: http://localhost:3000/
- Day 2: http://localhost:3000/day-2
- Day 3: http://localhost:3000/day-3
- Day 4: http://localhost:3000/day-4
