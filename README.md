# Flash Chat

Проект для челленджа **AI Advent Challenge #9**, задание **Day 3**.
Автор: **Roman Sukhin** (@mimiq43).

Лендинг-плейграунд для диалога с любой OpenAI-совместимой моделью (DeepSeek,
OpenAI, OpenRouter, Ollama и т.п.): стриминговые ответы через серверный маршрут
Next.js, API-ключ не покидает сервер.

Стек: Next.js 16 (App Router), TypeScript, Tailwind CSS v4.

## Задание Day 3: разные способы рассуждения

Одна задача решается через API четырьмя способами, ответы сравниваются между
собой и с эталоном. Страница — `/day-3`.

| # | Способ | Что уходит в API | Запросов |
| - | ------ | ---------------- | -------- |
| 1 | Прямой ответ | только условие задачи, без system prompt | 1 |
| 2 | Пошагово | system prompt «разбей на шаги, выпиши промежуточные величины, проверь подстановкой» | 1 |
| 3 | Мета-промпт | сначала модель пишет промпт для этой задачи, затем этот промпт уходит как system prompt второго запроса | 2 |
| 4 | Группа экспертов | аналитик, инженер и критик решают параллельно, четвёртый запрос сводит их мнения в общий ответ | 4 |

Все четыре способа работают в одинаковых условиях: одна и та же задача,
`temperature: 0`, `thinking: {"type":"disabled"}`, `max_tokens: 1400`.
Встроенный reasoning отключён намеренно — с ним модель рассуждает пошагово сама
и разница между способами 1 и 2 исчезает.

Единственная общая добавка ко всем промптам — требование закончить сообщение
строкой `ОТВЕТ: <значение>`. Она не подсказывает метод решения, но позволяет
вытащить финальный ответ и сверить его с эталоном автоматически.

### Как измеряется точность

У каждой задачи есть эталонный ответ. Строка `ОТВЕТ:` нормализуется (регистр,
кавычки, десятичная запятая) и сверяется со списком допустимых формулировок, а
интерфейс показывает вердикт: совпал с эталоном, не совпал, строки `ОТВЕТ` нет.
Кроме точности страница показывает время способа целиком, длину ответа в
символах и число запросов к API — цену рассуждения.

### Задачи

Четыре пресета плюс поле «Своя задача» (условие + эталонный ответ).

| Задача | Тип | Эталон |
| ------ | --- | ------ |
| Какая буква стоит на седьмом месте с конца в слове «делопроизводство»? | символьная | в |
| У Маши есть 3 брата и 2 сестры. Сколько сестёр у брата Маши? | логическая | 3 |
| Сколько раз буква «о» встречается в предложении «Около колодца кольцо не найдёшь»? | счётная | 7 |
| Минимальное число сравнений, чтобы найти минимум и максимум в массиве из 100 элементов | алгоритмическая | 148 (3n/2 − 2) |

Первые три задачи подобраны эмпирически: на них модель ошибается хотя бы одним
из способов. Четвёртая контрольная — её модель решает верно всегда, и на ней
видно, что разница между способами остаётся только в цене и длине ответа.

## Результаты прогона

Модель `deepseek-v4-flash`, прогон 3 сентября 2026 года, по одному запуску на
каждую пару «задача × способ».

| Задача (эталон) | 1. Прямой | 2. Пошагово | 3. Мета-промпт | 4. Эксперты |
| --------------- | --------- | ----------- | -------------- | ----------- |
| Буква по позиции (в) | ✗ «з» | ✓ «в» | ✓ «в» | ✗ «з» |
| Сёстры и братья (3) | ✓ 3 | ✓ 3 | ✓ 3 | ✓ 3 |
| Буквы во фразе (7) | ✓ 7 | ✓ 7 | ✗ 5 | ✗ 6 |
| Минимум и максимум (148) | ✓ 148 | ✓ 148 | ✓ 148 | ✓ 148 |
| **Верных ответов** | **3 из 4** | **4 из 4** | **3 из 4** | **2 из 4** |
| Суммарное время | 7 с | 10 с | 13 с | 19 с |
| Суммарная длина финальных ответов | 1527 симв. | 3111 симв. | 212 симв. | 2538 симв. |

### Отличаются ли ответы

Да, и расхождения приходятся именно на задачи-ловушки. На вопросе о букве по
позиции прямой ответ и группа экспертов уверенно дали «з» (восьмая с конца), а
пошаговое решение и мета-промпт — верное «в». На подсчёте букв, наоборот,
ошиблись более сложные способы: мета-промпт дал 5, эксперты — 6 при эталоне 7.
На контрольной алгоритмической задаче все четыре способа совпали.

### Какой способ дал наиболее точный результат

Пошаговое решение: 4 из 4 при вдвое меньшей цене, чем у группы экспертов.
Два наблюдения из этого прогона:

- **Мета-промпт вредит там, где сам себе запрещает рассуждать.** Для задачи о
  подсчёте букв модель написала себе разумный промпт с разбором по словам, но
  закончила его требованием «в ответе укажи только итоговое число, без
  пояснений» — и следующий запрос вернул голое `ОТВЕТ: 5`, без единой выкладки.
  Отсюда и 212 символов суммарно: способ систематически подавляет рассуждение,
  которое сам же предписывает.
- **Группа экспертов усиливает согласованную ошибку.** На подсчёте букв аналитик
  и инженер независимо дали 6, критик — 5; ведущий отбросил критика как
  «допустившего арифметическую ошибку» и утвердил 6. Большинство оказалось не
  ближе к истине, а лишь увереннее в себе, при этом способ стоит 4 запроса и
  самое долгое время из всех.

## Запуск

```bash
cp .env.example .env.local   # заполните OPENAI_BASE_URL, OPENAI_API_KEY, OPENAI_MODEL
npm install
npm run dev
```

Приложение поднимется на http://localhost:3000, страница задания — на
http://localhost:3000/day-3.

## Конфигурация (.env.local)

- `OPENAI_BASE_URL` — базовый URL провайдера, например `https://api.deepseek.com/v1`.
- `OPENAI_API_KEY` — ключ API.
- `OPENAI_MODEL` — имя модели, например `deepseek-v4-flash`. Показывается на
  сайте динамически.

## Как устроено

- `src/lib/day3.ts` — задачи с эталонами, промпты всех четырёх способов, общие
  параметры сэмплинга и проверка ответа (`extractAnswer`, `verifyAnswer`).
- `src/lib/day3-runner.ts` — сценарии способов: каждый раскладывается на фазы,
  каждая фаза — отдельный стриминговый запрос к `/api/chat`.
- `src/components/reasoning-lab.tsx` — выбор задачи, параллельный запуск четырёх
  способов, отмена, метрики.
- `src/components/reasoning-pane.tsx` — панель одного способа: фазы, вердикт,
  время, длина.
- `src/components/reasoning-summary.tsx` — итоговая таблица сравнения.
- `src/app/api/chat/route.ts` — серверный маршрут: проксирует запрос в
  OpenAI-совместимый API (`stream: true`), превращает SSE в текстовый поток,
  валидирует необязательные `system`, `temperature`, `max_tokens`, `thinking`.
  Без заполненного env отвечает явной ошибкой.
- `src/app/page.tsx` и `src/components/chat.tsx` — лендинг и чат из задания
  Day 1: стриминг, остановка генерации, Markdown-рендер ответов.
