# Flash Agent

Проект для челленджа **AI Advent Challenge #9**, задание **Day 6**.
Автор: **Roman Sukhin** (@mimiq43).

Простой чат с отдельным AI-агентом. Пользователь отправляет сообщение в
интерфейсе, серверный агент добавляет системную роль, вызывает любую
OpenAI-совместимую LLM через HTTP и потоково возвращает ответ.

Стек: Next.js 16 (App Router), TypeScript, Tailwind CSS v4.

## Задание Day 6: первый агент

`ChatAgent` — самостоятельная серверная сущность, а не имя для одного вызова
`fetch`. Внутри него находятся:

- конфигурация провайдера и модели;
- системная инструкция, определяющая роль агента;
- формирование запроса к LLM;
- обработка ошибок провайдера;
- преобразование SSE-ответа в поток текста для интерфейса.

Маршрут `/api/chat` отвечает только за HTTP-границу приложения: проверяет
входной JSON, передаёт историю диалога агенту и возвращает полученный поток.
Он не знает URL метода провайдера, формат авторизации или устройство ответа
модели.

## Поток данных

```text
Пользователь
    │ сообщение + история
    ▼
POST /api/chat
    │ проверенные ChatMessage[]
    ▼
ChatAgent.respond()
    │ system prompt + история, HTTP
    ▼
OpenAI-совместимый API
    │ SSE
    ▼
ChatAgent
    │ текстовый поток
    ▼
Интерфейс чата
```

Агент учитывает предыдущие сообщения диалога. API-ключ остаётся на сервере и
никогда не передаётся браузеру.

## Как запустить

```bash
npm install
cp .env.example .env.local
npm run dev
```

Заполните `.env.local`:

```dotenv
OPENAI_BASE_URL=https://api.deepseek.com/v1
OPENAI_API_KEY=sk-...
OPENAI_MODEL=deepseek-v4-flash
```

Подойдёт любой провайдер с OpenAI-совместимым методом
`POST /chat/completions`: DeepSeek, OpenAI, OpenRouter или локальный Ollama.

Откройте страницу [http://localhost:3000/day-6](http://localhost:3000/day-6),
введите сообщение и дождитесь ответа агента.

## Структура

```text
src/
  app/
    api/chat/route.ts    HTTP-адаптер между интерфейсом и агентом
    day-6/page.tsx       страница задания и интерфейс чата
  components/
    chat.tsx             история, отправка сообщений и потоковый вывод
    site-header.tsx      навигация между заданиями
  lib/
    chat-agent.ts        агент: роль, вызов LLM и обработка ответа
```

## Критерии результата

- агент принимает сообщения пользователя;
- агент корректно вызывает LLM через HTTP API;
- ответ модели отображается в интерфейсе;
- запрос и ответ провайдера полностью инкапсулированы в `ChatAgent`;
- ошибки конфигурации и API возвращаются интерфейсу в явном виде.
